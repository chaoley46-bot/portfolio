Projet · UDAF 47

Système d'inventaire du parc informatique

Suivi du parc de postes de l'association : liste consultable depuis un PC ou un téléphone, publiée sur GitHub Pages sous forme chiffrée, et saisie terrain possible sans réseau interne.

GitHub PagesJavaScriptChiffrement AES-256GitHub IssuesPHP CLI
Le projet

Savoir à tout moment quels postes sont à jour (Windows 11, batterie), où ils se trouvent et à qui ils sont attribués, y compris pour un technicien en déplacement.

Ce qui a été mis en place

  • Inventaire côté osTicket (équipements, attributions, réservations) avec export
  • Page web du parc PC : filtres, compteurs, PC « mis à jour » en vert, import d'une liste de numéros
  • Liste chiffrée (AES-256-GCM, clé dérivée du mot de passe par PBKDF2) : le dépôt est public mais les données restent illisibles
  • Fusion automatique entre l'inventaire osTicket et la page, avec règles de priorité
  • Saisie terrain depuis un téléphone via un formulaire d'Issue GitHub, synchronisé par un script planifié

Technologies & notions

  • JavaScript natif (aucune dépendance) et Web Crypto API
  • GitHub Pages, API GitHub et Issues
  • Script PHP en ligne de commande + tâche planifiée Windows
  • Sécurité : chiffrement, jetons à portée limitée, gestion de mot de passe
  • Interface responsive (PC / téléphone)
