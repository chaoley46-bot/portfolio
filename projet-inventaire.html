Projet · UDAF 47

Système d'inventaire du parc informatique

Suivi du parc informatique de l'association : un module inventaire intégré au panneau agent osTicket sur PC, et une page du parc PC chiffrée sur GitHub Pages, consultable depuis un téléphone.

osTicketPHP / MySQLJavaScriptGitHub PagesChiffrement AES-256
Le projet

Savoir à tout moment quels postes sont à jour (Windows 11, batterie), où ils se trouvent et à qui ils sont attribués, y compris pour un technicien en déplacement.

Ce qui a été mis en place

  • Module inventaire dans osTicket : stock, attributions par poste, réservations, perdu / hors service, export Excel des PC
  • Suivi de chaque ordinateur : Windows 11, batterie changée, date de dernière maintenance, notes
  • Historique complet de chaque action (qui, quoi, pour qui, quand) et recherche globale
  • Page web du parc PC pour le téléphone : filtres, compteurs, PC « mis à jour » en vert, import d'une liste de numéros
  • Liste chiffrée (AES-256-GCM, clé dérivée du mot de passe par PBKDF2) : le dépôt est public mais les données restent illisibles
  • Publication et import entre l'inventaire osTicket et la page, avec règles de priorité

Technologies & notions

  • PHP et ORM d'osTicket, base MySQL / MariaDB, permissions par rôle
  • JavaScript natif (aucune dépendance) et Web Crypto API
  • GitHub Pages et API GitHub
  • Sécurité : chiffrement, jetons à portée limitée, gestion de mot de passe
  • Interface responsive (PC / téléphone)
